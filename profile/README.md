# Taligent

**Ingeniería de datos · Inteligencia Artificial · Cloud · Software & BI**

Diseñamos y operamos plataformas de datos, agentes de IA e infraestructura cloud
para empresas — desde el data lakehouse y los pipelines de datos hasta aplicaciones
a medida, automatización de procesos y Business Intelligence.

</div>

---

## 🧭 Qué hacemos

- **Plataformas de datos & Lakehouse** — arquitecturas Medallion (Bronze → Silver → Diamond/Gold), Data Mesh (dominios y subdominios) y linaje de datos end-to-end.
- **Inteligencia Artificial & Agentes** — agentes especializados, workflows agénticos y asistentes conversacionales integrados a procesos de negocio.
- **Infraestructura Cloud (IaC)** — despliegues reproducibles en AWS, Azure y GCP gestionados 100% como código.
- **Software a medida** — aplicaciones web full-stack, backoffices y portales para clientes.
- **Business Intelligence** — tableros, design systems de BI y temas corporativos.
- **Automatización de procesos** — orquestación de flujos y bots que reemplazan tareas manuales.
